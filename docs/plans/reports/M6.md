### Decision: the binding for the spec (Niels, 2026-11-05)

The 0.3.1 binding calls `newChart(el, x)` and, when Shiny draws the chart
again, `chart.update(x)`. With `widget$x = list(spec = ...)`, `x` has no
version and would be drawn as a render model; and `update()` deep-merges a
spec, so a component left out of a redraw would stay. Decided: the binding
changes on this repo's `m6-js-library` (`x.spec` when present, and
`setSpec()` on a redraw). Until Niels approves a 0.3.2 release before the
CRAN checks (M6.6), the R branch vendors this branch's build with
`dev/update_js.R --dist <dir>`, checksums checked the same way; then it
is vendored again from the release.
