## M3.1: esbuild, no code changes

**Commit:** 4a2fd24 on m3-modules-schema

**Done:**
- `package.json`: `esbuild` 0.28.2 as a devDependency, pinned exactly.
- `scripts/bundle.mjs`: the esbuild settings (IIFE, not minified, `d3` read
  from the page's global). `geneviewer.js` and `chart.js` are still
  classic scripts, so a small plugin joins them, unchanged, into one module
  `geneviewer:scripts`. This plugin goes in M3.2.
- `src/index.js`: the entry. It exports `newChart` and `version`, and
  `chartToSVG` and `chartToPNG` (see below).
- `scripts/build.mjs`, `files.mjs`, `check.mjs`: `dist/geneviewer.js` is
  the esbuild bundle; the other dist files are copied as before.
- **Old globals (decided by Niels during this step).** Before, every
  top-level function of `geneviewer.js` was a page global. Some tests
  outside this repo call them:
  - the app's `tests/browser/chart-wide-drag.cjs` calls `chartToSVG(el)`;
  - the R package's `test-color-bar.R` and `test-zoom.R` call
    `chartToSVG(el)`, and `test-png-export.R` calls `chartToPNG(el)`;
  - `test-render-events.R` replaces `window.makeLinks` to simulate a failed
    draw.

  Niels chose aliases in the R binding:
  - `geneviewer.chartToSVG` and `geneviewer.chartToPNG` are exported.
  - `src/htmlwidgets/geneviewerwidget.js` sets `window.chartToSVG` and
    `window.chartToPNG` to them until M6.
  - The `makeLinks` test cannot work on a bundle. M6 rewrites it.
- **Tests:**
  - `test/warnings.cjs` called `getColorScale` as a global. It now uses a
    test-only bundle: `scripts/build-test.mjs` builds
    `test/harness/internals.js` into `test/harness/build/internals.js`
    (ignored by git) as the global `geneviewerInternals`, and the test adds
    it to its page.
  - `scripts/test-docker.sh` builds it before the tests.
- Workflows (`ci`, `test`, `release`, `pages`): `npm ci` before building,
  since the build now needs esbuild.
- README: build section.

**Deviations from the plan:**
- The entry joins the two scripts with a plugin. They cannot be imported
  separately: `chart.js` uses `geneviewer.js`'s functions as globals.
- The `chartToSVG`/`chartToPNG` exports and aliases (above).

**Found along the way:**
- esbuild drops comments, apart from licence comments. The bundle is
  readable and not minified, but it has no comments. CRAN asks for
  readable source, which this still is. The commented source is in this
  repo.
- esbuild warns about two duplicate keys in one object literal in
  `geneviewer.js` (`strokeWidth`, `cursor`). The later key wins, as before.
  M3.2 removes the dead first key, since its check needs zero warnings.
- For M6: `test-render-events.R` must stop replacing `window.makeLinks`.
  The R and app tests should use the chart's `toSVG`/`toPNG`, so the
  aliases can go.
