## M1.3: Baselines

**Commit:** 51e4727

**Done:** baselines for all 190 fixtures. Three problems found and fixed on
the way:

1. **Payloads.** `widget$x` is not what R sends. `GC_chart()` has a
   `preRenderHook` (`render_theme`) that adds `size` and `dataColumns` and
   compacts the data. Both export scripts now use
   `htmlwidgets:::createPayload()`. The site examples were re-exported the
   same way.
2. **Emulation.** The first image ran amd64 Chrome under emulation on Apple
   silicon. Chrome then misread numbers (`0.2` as `0`) and drew genes at
   random positions. The image now runs natively on arm64, with Chromium
   pinned by `playwright-core` 1.64.1; puppeteer has no arm64 Linux
   Chrome.
3. **Pointer.** The pointer starts at the page corner, over the chart, so
   the `GC_trackMouse` tooltip sometimes showed. The harness page now
   starts the chart 50 px in.

**Checks run:**
- `npm test`: 190 passed, three runs in a row; about 25 s.
- Six varied fixtures (zoom, protein alignment, transcripts, annotations,
  patterns, links with colour bar) checked by eye: they match the R
  vignettes.

**Found along the way:** what looked like a zoom bug (`GC_zoom(range = )`
drawing `NaN`) was the emulation problem; there is no R bug.
