## M5.1: Builds

**Commit:** see git log, "M5.1" on m5-npm

**Done:**
- `package.json`: `d3` moves from `peerDependencies` to `dependencies`,
  `^7.8.5`; the lock file pins 7.8.5, the version the R package ships, so
  the bundled builds draw with the same D3.
- `scripts/files.mjs`, `scripts/bundle.mjs`, `scripts/build.mjs`: four
  bundles of `src/lib/index.js`:
  - `geneviewer.min.js`: IIFE, global `geneviewer`, D3 bundled, minified,
    linked source map (sources included);
  - `geneviewer.mjs`: ESM, `import * as d3 from "d3"`;
  - `geneviewer.standalone.mjs`: ESM, D3 bundled, minified, source map;
  - `geneviewer.core.js`: IIFE, the page's global `d3`, not minified.
  The code names `d3` as a global; for the ESM and bundled builds esbuild
  injects `src/d3.js`, which imports it from the package.
  Copied: `geneviewer.css` (was `styles.css`), `themes.json`,
  `geneviewerwidget.js`.
- `scripts/sums.mjs`: `SHA256SUMS` over every file in `dist/`, as the last
  step of `npm run build`, so it covers the type definitions too.
- **Styles:** `src/lib/styles.js` adds `src/styles.css` (bundled as text)
  once per document, as `<style data-geneviewer>` first in the head, on the
  first `newChart`. `newChart(el, spec, { injectStyles: false })` turns it
  off (JSDoc in `ChartOptions`).

  draws with the injected styles. `?build=min` loads `geneviewer.min.js`
  (default core); `node test/run.cjs --build min`. `npm test` also draws
  every fixture with the min build (direct mode). `test/update.mjs`: the
  stylesheet is added once, and not with `injectStyles: false`.
- `scripts/try-app.sh` puts the core build, `geneviewer.css` and the binding
  in place of the R package's `geneviewer.js`, `styles.css` and binding.
- `scripts/build-site.mjs` copies the core build and `geneviewer.css` under
  the names the pages use (the site is rewritten in M5.5).
