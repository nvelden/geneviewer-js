## M5.1: Builds

**Commit:** see git log, "M5.1" on m5-npm

**Done:**
- `package.json`: `d3` moves from `peerDependencies` to `dependencies`,
  `^7.8.5`; the lock file pins 7.8.5, the version the R package ships, so
  the bundled builds draw with the same D3.
- `scripts/files.mjs`, `scripts/bundle.mjs`, `scripts/build.mjs`: four
  bundles of `src/lib/index.js`:
  - `geneviewer.min.js`: IIFE, global `geneviewer`, D3 bundled, minified,
    linked source map (sources included);
  - `geneviewer.mjs`: ESM, `import * as d3 from "d3"`;
  - `geneviewer.standalone.mjs`: ESM, D3 bundled, minified, source map;
  - `geneviewer.core.js`: IIFE, the page's global `d3`, not minified.
  The code names `d3` as a global; for the ESM and bundled builds esbuild
  injects `src/d3.js`, which imports it from the package.
  Copied: `geneviewer.css` (was `styles.css`), `themes.json`,
  `geneviewerwidget.js`.
- `scripts/sums.mjs`: `SHA256SUMS` over every file in `dist/`, as the last
  step of `npm run build`, so it covers the type definitions too.
- **Styles:** `src/lib/styles.js` adds `src/styles.css` (bundled as text)
  once per document, as `<style data-geneviewer>` first in the head, on the
  first `newChart`. `newChart(el, spec, { injectStyles: false })` turns it
  off (JSDoc in `ChartOptions`).
- Tests: the harness page no longer links the stylesheet, so every test
  draws with the injected styles. `?build=min` loads `geneviewer.min.js`
  (default core); `node test/run.cjs --build min`. `npm test` also draws
  every fixture with the min build (direct mode). `test/update.mjs`: the
  stylesheet is added once, and not with `injectStyles: false`.
- `scripts/try-app.sh` puts the core build, `geneviewer.css` and the binding
  in place of the R package's `geneviewer.js`, `styles.css` and binding.
- `scripts/build-site.mjs` copies the core build and `geneviewer.css` under
  the names the pages use (the site is rewritten in M5.5).

**Checks run:**
- `npm test`: fixtures 618 passed with the core build (three modes) and 206
  with the min build; interaction, update, save, two charts, site, warnings:
  all passed.
- `npm run try-app`: app testthat passed; browser tests 12 passed, 0 failed
  (the first run had 3 time-outs while the screen was locked; the rerun
  passed).
- `npm run check`, `types:test`: ok; `types:src`: the same 34 errors.

## M5.3: Package metadata

**Commit:** see git log, "M5.3" on m5-npm

**Done:**
- `package.json`: `name: "geneviewer"`, `private` removed, `version:
  "0.3.0"` (also in `src/lib/chart.js`), description, keywords, homepage
  (the docs site), bugs, author; `module`, `types`, `unpkg`, `jsdelivr`;
  `exports`: `"."` (types, import `geneviewer.mjs`), `"./standalone"`
  (types, import `geneviewer.standalone.mjs`), `"./geneviewer.css"`,
  `"./package.json"`; no CommonJS entry; `files`; `sideEffects: ["*.css"]`.
- `scripts/bundle.mjs`: `ignoreAnnotations`, because `sideEffects` would
  otherwise let esbuild drop the library's own component modules, which add
  to `container.prototype` when imported. Each file in `dist/` is one
  module, so the field is right for users' bundlers. D3 is no longer
  tree-shaken by its annotations either: `geneviewer.min.js` is 480 kB
  instead of 477 kB.
- README rewritten for npm users: install, CDN, a first chart, a bundler
  example, the files; the development notes follow under "Development",
  updated for the new builds, the three test modes and compile().

**Checks run:** `npm pack --dry-run`: 16 files: `dist/` (11 files),
`README.md`, `LICENSE.md`, `LICENSE-THIRD-PARTY.md`, `package.json`;
1.4 MB packed (the two source maps are 1.9 MB each unpacked).

**Deviations from the plan:** `"./package.json"` in `exports`, which some
