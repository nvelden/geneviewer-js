Examples

Every chart here is drawn live by geneviewer-js v0.2.0. Hover over genes for tooltips, or over a chart for its save button (SVG or PNG).

The code shown is the R code that produced each chart, because the JavaScript API is not built yet. When it is, each example will show its JavaScript too.

Data: the example datasets of the geneviewer R package. geneviewer-js is MIT licensed.
