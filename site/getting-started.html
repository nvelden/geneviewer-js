Getting started

Install

With a script tag, which defines the global geneviewer and includes D3:

<script src="https://cdn.jsdelivr.net/npm/geneviewer@0.3/dist/geneviewer.min.js"></script>

Or from npm, for a bundler such as Vite or webpack; this build imports d3 from npm, so a project that uses D3 loads it once:

npm install geneviewer
import { newChart } from "geneviewer";

The library adds its styles to the page with the first chart. TypeScript types are included.

A first chart

A chart is drawn into an element, which sets its size, from a spec: the data and what to draw.

<div id="chart" style="height: 220px"></div>
<script>
  const genes = [
    { cluster: "ophA", name: "ophB1", start: 2522, end: 4276, class: "Monooxygenase" },
    { cluster: "ophA", name: "ophC", start: 5286, end: 4718, class: "NTF2-like" },
    { cluster: "ophA", name: "ophA", start: 9536, end: 10904, class: "Methyltransferase" },
    { cluster: "dbophA", name: "dbophB1", start: 1000, end: 2700, class: "Monooxygenase" },
    { cluster: "dbophA", name: "dbophA", start: 6100, end: 7400, class: "Methyltransferase" },
  ];

  const chart = geneviewer.newChart("#chart", {
    version: 1,
    data: genes,
    fields: { cluster: "cluster", group: "class" },
    labels: { label: "name" },
    clusterLabel: {},
  });
</script>

Data and fields

data is the gene table: an array of rows, as above, or an object of columns ({ start: [...], end: [...] }), as R and Python send it. fields names the columns:

  • start and end: the gene's positions (default: the columns start and end). A gene whose start is after its end is on the reverse strand.
  • cluster: which cluster a gene is in; without it, all genes are one cluster.
  • group: colours the genes and fills the legend.
  • strand: 1, forward, + or sense; -1, 0, reverse, -, antisense or complement.

Other columns can be used in labels, tooltips (tooltip: { formatter: "{name}: {start}-{end}" }) and styles.

Parts of the chart

Each other key of the spec sets one part: title, labels, legend, scale, links, theme and more. A part can be an array of entries; an entry with clusters applies only to those clusters. Every option is in the API reference.

labels: [
  { label: "name" },
  { clusters: ["dbophA"], fontStyle: "normal" },
],
theme: "classic",

Updating

update() merges a partial spec into the chart's spec and draws again; tables (data, links.data) are replaced whole. setSpec() replaces the spec.

chart.update({ title: { title: "OphA clusters" }, theme: "dark" });
chart.update({ data: moreGenes });
const spec = chart.getSpec();

Events

Turn interactions on with events, then listen with on(), which gives a function that stops listening. Each event is also a geneviewer:<name> DOM event on the element.

chart.update({ events: { click: true, select: true } });
const stop = chart.on("select", (event) => console.log(event.detail));
document.getElementById("chart")
  .addEventListener("geneviewer:click", (event) => console.log(event.detail));

Export

The toolbar's save button downloads the chart as SVG or PNG. From code:

const svg = chart.toSVG();          // text
const png = await chart.toPNG();    // a Blob

Pass saveAs(blob, filename) to newChart's options to save files your own way.
