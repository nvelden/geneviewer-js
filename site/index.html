Gene cluster charts for the web

geneviewer draws interactive gene clusters, transcripts and genome alignments in the browser with D3. One chart spec, in JavaScript, R or soon Python, draws the same chart: it is also the drawing engine of the geneviewer R package.

0.3.0 is being released. The npm install and jsDelivr instructions work once it is on npm.

npm install geneviewer

Start with the getting started guide, browse the examples, or look up an option in the API reference.

What it draws

Genes

Arrows, boxes or rounded boxes on a sequence line, coloured by group, with patterns, labels and tooltips.

Transcripts

Exons, introns and UTRs for splice variants.

Links

Connections between homologous genes or alignment blocks, shaded by identity, with inversions marked.

Layout

Titles, cluster labels, legends, coordinates, scale bars, scale breaks and annotations.

Themes

Built-in themes and colour palettes, or your own colours per group.

Interaction

Zoom slider, selection, dragging labels and titles, undo and redo, and SVG or PNG export.

Using it

From JavaScript Available

A script tag or npm install geneviewer, then one call: 

const chart = geneviewer.newChart("#chart", {
  version: 1,
  data: genes,
  fields: { cluster: "cluster", group: "class" },
  labels: { label: "name" },
  links: { data: homologs, measure: "identity" },  // pairs of genes
});

See getting started and the API reference.

From R Available

The geneviewer package on CRAN builds charts from data frames and GenBank, GFF, FASTA and BED files, and draws them with this library. 

install.packages("geneviewer")

library(geneviewer)
GC_chart(ophA_clusters, group = "class", cluster = "cluster") %>%
  GC_labels("name") %>%
  GC_links("class", measure = "identity")

See the R package documentation.

In the browser, without code Available

The Gene Cluster Dashboard loads CSV, GenBank and FASTA files and lets you design a chart by point and click. It runs entirely in your browser.

From Python Planned

A geneviewer Python package for Jupyter and Shiny for Python, built on the same JavaScript library, so charts look and behave the same in every language.
