Gene cluster charts for the web

geneviewer-js draws interactive gene clusters, transcripts and genome alignments in the browser with D3. It is the drawing engine of the geneviewer R package, being made into a standalone JavaScript library.

Pre-release. The charts on this site are drawn by geneviewer-js v0.2.0, the code in the development version of the R package. Today the library is used through the R package and the Gene Cluster Dashboard. The standalone JavaScript API, geneviewer.newChart(), is designed but not built yet; the API page shows the plan.

What it draws

Genes

Arrows, boxes or rounded boxes on a sequence line, coloured by group, with patterns, labels and tooltips.

Transcripts

Exons, introns and UTRs for splice variants.

Links

Connections between homologous genes or alignment blocks, shaded by identity, with inversions marked.

Layout

Titles, cluster labels, legends, coordinates, scale bars, scale breaks and annotations.

Themes

Built-in themes and colour palettes, or your own colours per group.

Interaction

Zoom slider, selection, dragging labels and titles, undo and redo, and SVG or PNG export.

Using it today

From R Available

The geneviewer package on CRAN builds charts from data frames and GenBank, GFF, FASTA and BED files, and draws them with this library. 

install.packages("geneviewer")

library(geneviewer)
GC_chart(ophA_clusters, group = "class", cluster = "cluster") %>%
  GC_labels("name") %>%
  GC_links("class", measure = "identity")

See the R package documentation.

In the browser, without code Available

The Gene Cluster Dashboard loads CSV, GenBank and FASTA files and lets you design a chart by point and click. It runs entirely in your browser.

From JavaScript Planned

A script tag or npm install geneviewer, then one call: 

const chart = geneviewer.newChart("#chart", {
  data: genes,
  fields: { cluster: "cluster", start: "start", end: "end", group: "class" },
  labels: { label: "name" },
  links: { data: homologs, measure: "identity" },  // pairs of genes
});

See the planned API.

From Python Planned

A geneviewer Python package for Jupyter and Shiny for Python, built on the same JavaScript API, so charts look and behave the same in every language.

Roadmap

  1. Reference fixtures: every R chart feature recorded as a test, checked on every change.
  2. Library core: rendering and interaction moved out of the R binding into newChart().
  3. Modules and schema: the code split into modules; the chart spec defined as a JSON Schema.
  4. Chart spec in JavaScript: splitting clusters, per-cluster settings, layout and themes resolved by the library instead of R, matching R exactly. Data processing stays in R and Python.
  5. npm 0.3.0: builds for script tags and bundlers, TypeScript types and a full API reference.
  6. R package 0.3.0 on the library, and the Gene Cluster Dashboard with it.
  7. Python package 0.1.0 for Shiny for Python, with file readers and alignment.
  8. 1.0.0 once R and Python both use the library.

Follow progress on GitHub. Releases are listed on the releases page.
